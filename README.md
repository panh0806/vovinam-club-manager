
# Vovinam Club Manager - Hệ thống quản lý CLB Vovinam

Đây là bài tập dự án môn học Blockchain. Hệ thống ứng dụng Smart Contract để quản lý minh bạch việc điểm danh và đóng quỹ của các thành viên câu lạc bộ Vovinam.

## Tính năng chính
- **Điểm danh:** Thành viên kết nối ví MetaMask và xác nhận điểm danh buổi tập.
- **Đóng quỹ:** Cho phép thành viên nộp quỹ CLB (bằng ETH) trực tiếp vào Smart Contract.
- **Quản lý quỹ:** Chỉ tài khoản của Ban chủ nhiệm/Thư ký (Admin) mới có quyền rút quỹ ra để tổ chức sự kiện.

##  Công nghệ sử dụng
- **Smart Contract:** Solidity, Remix IDE
- **Frontend Giao diện:** HTML, JavaScript
- **Web3 Integration:** Thư viện Ethers.js, Ví MetaMask

## Hướng dẫn chạy thử
1. Clone dự án về máy.
2. Mở file `index.html` bằng tiện ích **Live Server** trên VS Code.
3. Đảm bảo trình duyệt đã cài đặt extension **MetaMask** và kết nối mạng thử nghiệm (Testnet/Local).
4. Bấm "Kết nối Ví MetaMask" và sử dụng các tính năng.
